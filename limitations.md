# Limitations

1. DHT11 has limited measurement range and accuracy compared with higher-grade sensors.
2. Its response and sampling rate are relatively slow.
3. The dashboard displays latest readings only; no historical database is implemented.
4. The dashboard is intended for local-network access, not direct public internet access.
5. Wi-Fi availability and network configuration affect access.
6. Sensor placement, airflow, heat sources, and condensation can affect readings.
7. Only temperature and relative humidity are measured.
8. No calibration against a reference instrument is included.
9. This is an educational prototype, not a certified environmental instrument.
10. Wi-Fi credentials are configured in source code and must be kept out of public commits.
