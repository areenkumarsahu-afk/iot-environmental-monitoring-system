# Future Improvements

These are proposed extensions, not features implemented in the current version.

1. **Historical logging:** store timestamped readings for later review.
2. **Charts:** visualize temperature and humidity trends.
3. **Cloud connectivity:** optionally publish readings to an IoT platform.
4. **Additional sensors:** add appropriate sensors for particulate matter, CO2, light, or pressure.
5. **Alerts:** provide configurable notifications when readings cross defined thresholds.
6. **Improved sensing:** compare a higher-accuracy sensor such as DHT22 against a reference instrument.
7. **Security:** add authentication and appropriate controls before access beyond a trusted LAN.
8. **Power optimization:** investigate low-power operation and battery management.
